# Chatbot BYTECORE - Proyecto

## Descripción

Cora es un asistente virtual desarrollado como parte de un proyecto universitario.

Su objetivo es brindar información básica sobre los servicios de la empresa y permitir que los usuarios soliciten un servicio mediante una conversación sencilla e interactiva.

El chatbot fue integrado en el sitio web del proyecto y cuenta con un diseño responsive para adaptarse a diferentes dispositivos.

## Características

- Chatbot interactivo llamado Cora.
- Menú principal con opciones numeradas.
- Opción para regresar al menú principal.
- Información sobre los servicios disponibles.
- Información de contacto.
- Formulario conversacional para solicitar servicios.
- Captura del nombre del cliente.
- Captura y validación del correo electrónico.
- Captura del número telefónico.
- Registro de la descripción de la solicitud.
- Confirmación de la información antes de guardar la solicitud.
- Almacenamiento local de las solicitudes mediante `localStorage`.
- Diseño responsive para computadores, tablets y celulares.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
- Visual Studio Code
